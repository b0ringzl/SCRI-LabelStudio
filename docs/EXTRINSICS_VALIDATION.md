# 外参 CSV 候选解释试验（2026-11-05）

## 结论

已对用户提供的单行六自由度 CSV 和 C++ 的 `Rz × Ry × Rx` 公式执行实景对照。**当前不能确认该 CSV 是尖沙咀整套设备的固定安装外参，也不能确认它的方向、平移单位或适用帧；没有验证达到 4°。** 保留为未验证候选，不自动修改工作台或标注位姿。文件来源和标定用途无法仅从一行数值反推。

表头 `roll_deg,pitch_deg,yaw_deg` 明确表示度。按度换算后，旋转变换量约 0.035913°；平移若以米解释，长度约 0.193449 m。把三个角度的原始数字直接传入 `sin/cos` 会得到约 2.06° 的变换量，本试验将它作为检查潜在读入错误的对照，不能因为代理分数稍好就推翻表头单位。这些都是变换量，不是配准误差。

## 本次实际执行

- 从 12 份 `pointcloud_DS_*.pcd` 读取、核对并缓存 7240756 个有限的 XYZ＋intensity 点；没有使用之前发现长度异常的彩色 PCD。
- 在同一条流的可覆盖轨迹上等间隔选择 20 帧，从 000000 至 003298，每帧确定性采样 30000 个附近地图点。10 帧用于选择全景零方位／镜像代理候选，另 10 帧用于比较 CSV 解释。**这里的留出帧没有独立真值位姿，不是 4° 精度测试集。**
- 解释组合：角度按度换弧度／原数字直接作弧度 × 米／厘米／毫米 × 矩阵正向／取逆 × FLU／FRU／RDF 光学系／当前 viewer 系，共 48 种；另加不使用 CSV 的单位矩阵对照。
- 在“原始 INS 投影”和“用选择帧确定的零方位／镜像代理候选”两个上下文中比较。全景水平方向按 4° 扫描全周，同时试验水平和垂直翻转。
- 先用 2048×1024，再用 4096×2048 全景复核，保持帧和点采样相同。累计执行 3920 次候选／单位矩阵投影评分，并另做全周扫描。
- 指标包括 NID、点云深度边缘到影像边缘的截断距离代理、有效投影点数、候选相对 INS 的射线方向改变量。帧级 bootstrap 区间用于查看稳定性，不能在空间相关帧与多重比较下解释为正式准确率保证。

所有试验假定所选基变换能将 CSV 放到 INS 平台系；实际 **LiDAR↔INS 平台变换仍未知**。四类轴约定使用的是源、目标共同换基，并未穷尽任意独立的传感器坐标重定义、所有旋转顺序、硬件时间延迟或全景拼接误差。

## 补充审阅 TREE 既有投影记录

用户随后提供了 `TREE/hk-tree-vmms/derived/temporal_lidar_projection`。已读取全部四份 JSON、生成脚本，并查看实际叠加图：

- 目录包含 004335、004338、004374 三组记录，来源是 **2023-10-27 何文田**，不是当前 2025-02-10 尖沙咀流。
- 两份逐时窗口投影报告采用 FLU 球面公式、逐扫描 INS 运动补偿，设置 yaw=180°、pitch=roll=0°、杆臂=0；报告同时注明精细安装角／杆臂参数缺失。180° 属于该数据流的零方位修正，不能作为本次 CSV 的独立六自由度标定真值，也不能直接套到尖沙咀。
- `frame_004338/panorama_handedness_report.json` 内部 `frame_id` 为 **004319**，与目录名不同；其生成脚本本来会按内部帧号建目录，因此现有文件可能经过复制或移动，不能仅凭目录名认定配对关系。`frame_004335` 的同名报告内部帧号与目录一致。

| 004319 | 正常公式、178° | 支持该组数据约 180° 零方位附近的一致性 |

## 能确定与仍不能确定的事项

| 事项 | 判断 |
| --- | --- |
| 数值和公式能否组成刚体变换 | 可以；已验证矩阵、逆矩阵和换基的代数性质 |
| 表头角度单位 | 按度解释；读取后转弧度再调用三角函数 |
| `readPoseCsv` 是否已转换弧度 | 没有函数源码，无法确认原程序是否已经转换 |
| 正向还是取逆，平移是 m/cm/mm | 已做实景对照，但证据不足以唯一确定 |
| 是固定设备外参还是单帧修正 | 单行文件无帧 ID、设备标识或标定记录，无法确定；跨帧应用未显示可依赖的稳定收益 |
| 是否对应当前测区，是否符合 4° | 没有独立参考，未验证；不能以分数改善替代真值误差 |

建议下一步用现有同名点工作台，在若干视角不同的静态建筑或标志角点上建立可复核参考，再联合估计共享安装外参及必要的逐帧残差。该 CSV 继续作为待比较候选，不再要求使用者先猜测它的含义。整体方案见 [4° 可行性方案](REGISTRATION_OPTIONS_4DEG.md)。

当前自动精配准使用无权重球面 NID 本机后端；部署、输入条件、质量检查与限制见 [自动配准说明](AUTOMATIC_REGISTRATION.md)。已有粗位姿仍是前提，候选须人工核验。

```powershell
py -3.11 -m venv .venv-extrinsics
.\.venv-extrinsics\Scripts\python.exe -m pip install -r scripts/requirements-extrinsics-validation.txt
.\.venv-extrinsics\Scripts\python.exe scripts/validate_extrinsics.py --vmms "C:\data\20250210-jianshazui" --frames "C:\data\frame_coordinates.csv" --extrinsics "C:\data\extrinsics_per_pair_6dof.csv" --output "local-samples/extrinsics-validation"
```

将示例数据根目录换为实际路径。激活独立环境后，也可运行 `Validate-Extrinsics-Windows.bat`，按顺序传入 VMMS 目录、INS 表、外参 CSV 和结果目录。本次实景试验使用本机已经安装的 Python 依赖，只读运行，没有修改现有环境或原始数据。
