# 0.13.0 · 四步工作流 Demo 与点径修复

旧 Demo 同时提供道路设施复核、工作台、任务列表、数据源、配准、标签和模型入口，工作台又嵌入配准步骤。本版把主导航统一为“数据 → 配准 → 标注 → 训练”，项目设置单独收纳标签与模型，明确每项功能的归属。

1. **重排全部主要页面**：新增 WorkflowShell、DataWorkspace、FrameNavigator、TrainingWorkspace 和统一样式；默认进入数据管理，场景由卡片选择，导入表单按需展开，原先单独的图片复核改为标注类型。
2. **配准与标注分离**：配准页独占位姿、同名点和投影核验。标注页只含标注工具、AI 审核、切帧、多视角目标定位与对象面板；相关快捷键只在点云标注页生效。
3. **点大小生效**：将用户倍率移到 GPU 自动点径限幅之后，修复近处点在上限时“＋/−”无变化；增加固定像素模式、滑杆和数值。标题栏“放大点云窗口”现在实际切全宽并可还原。
4. **讲清导入容量**：统一到数据页；150 MiB 为浏览器直读阈值，超限有明确提示与本机大点云路线。已有本机预处理可处理大源文件并生成全图采样显示，不宣称实现海量原始点流式加载。
5. **会话与训练归位**：图片文件引用、核验状态和当前图片跨页面保留；进度 ZIP 恢复放入数据页，蒸馏清单移到训练页，继续只导出已确认样本。实际训练后端未连接，不显示虚构训练进度。
6. **保持协作与双平台**：更新 README、UI 架构/设计说明、导入指南和本版本功能文档；新增工作流回归并接入 CI；生成 Windows/macOS 常规包和本地四场景包。

验证包括 TypeScript/Vite 构建、既有模型/蒸馏/配准/场景/同步回归、工作流 SSR 门控测试，以及 Windows 浏览器中的实际三文件组导入、阶段导航、图片会话保留、超限提示、GPU 点径变化和窗口尺寸变化。真实数据保留本地。完整功能与界面说明见 [工作流设计与验证](WORKFLOW_UI_0.13.0.md)。
