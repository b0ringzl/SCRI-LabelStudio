# 0.13.1 · 同步与独立观察切换保留视角

修复关闭“视角同步”时点云跳回全图透视视角的问题。现在独立观察从当前同步相机继续：位置、完整朝向（含 roll）、FOV 和 zoom 保留，不修改配准外参或标注。

## 行为

- 同步 → 自由观察：保留切换瞬间的画面，视角下拉显示“当前视角”。可继续左键环绕、滚轮缩放、右键平移。
- 自由观察 → 同步：沿用共享的最后同步朝向/FOV，光心恢复到当前全景帧对应的位姿。独立平移不会写成硬件外参。
- 透视、俯视、正视预设只在主动选择时应用；载入一份新的无位姿点云仍会正常进行初始全图取景。

## 实现

`PointCloudView.tsx` 移除由 linked 变化触发的预设重置，改为显式选择预设；控制器接管使用 layout effect，在下一次渲染前完成，避免旧环绕控制器抢先更新相机。

新增 `cameraOrbit.ts`，通过公开 API 重建 OrbitControls，丢弃旧拖动、平移和缩放的惯性。旋转支点放在当前视线前方 10 m，camera.up 从完整相机四元数计算，构造后恢复相机快照，再更新控制器。显式预设也重建控制器，避免沿用另一观察方向的 up 缓存。

回归使用实际 Three.js OrbitControls，在三组包含大倾角/roll 的相机姿态下连续更新 60 次，确认位置、四元数、FOV、zoom 没有漂移。真实浏览器测试覆盖：先环视/缩放和切帧、解除同步、独立拖动/缩放、重新同步、反复切换及主动选择预设；以实际渲染相机的 DOM 诊断值核对，而非只检查按钮状态。

双平台共用实现，常规包和含四场景的本机试用包均更新到 0.13.1。原有模型、配准、训练接口和保存格式保持兼容；真实数据保留本机。Windows 浏览器实测，实体 Mac 图形表现仍待验收。
