# 0.14.1：修正厚墙被拟合成薄面的问题

1. 新增“圈选范围”：完整物体（含侧面）或单个表面。新多帧对象默认整体；旧记录按单面解释，保留顶点、位姿和核验兼容。
2. 完整体积路径改为所有帧轮廓内、至少一帧近表面可见，保留被另一帧正面遮挡的侧面点；单面路径继续使用每帧近表面条件。
3. 整体方向由水平凸包最小面积搜索确定，避免正面加侧面采样使 PCA 倾斜。框局部 D 表示候选深度，并提示厚度需要核验。
4. 新增可选 observation.extent / triangulation.extent，仍使用 schemaVersion 0.2。混用单面/整体观测会拒绝定位。编辑顶点保留范围，修改范围清除旧候选，撤销恢复范围和候选。
5. 增加已知厚度 1.8 m 的旋转墙体、背景、单帧遮挡、范围混用与兼容回归。真实图书馆两帧六点外轮廓生成约 0.94 m 深度候选（975 支持点）；该值不是经过独立实测的真实厚度。
6. README、双平台说明、UI/模型接口及算法说明同步更新。Windows/macOS 常规包与含真实数据的本地试用包同步生成；不提交原始数据、用户备份或 ZIP。

本次发现实际内置浏览器仍缓存 0.13.0，已先备份其中两个对象，再打开保留已保存标注的新版工作台，逐项比较标注与位姿未变。完整操作、代码入口和限制见 [墙体厚度说明](WALL_VOLUME_0.14.1.md)。
