# 简化标注流程

## 这两种标注各解决什么问题

- **3D 框**标注一个物体或建筑构件的位置、范围和方向，适合标志牌、柱、独立设施等实例对象。
- **逐点类别**把点云表面涂成建筑立面、门窗、地面等语义类别，适合视频中展示的点云分类工作流。
- **全景点 / 多边形**在影像侧标记可见目标。3D 框与全景标记可共享对象 ID；逐点类别暂时只在点云侧保存。

## 3D 框：从初值到精修

1. 选类别，切到“3D 框”；俯视或透视下围住目标拖出矩形，自动得到初始中心、尺寸和水平角度。单击可先放一个默认框。
2. 点击框选中，按“定位到框”。
3. 切换“移动 / 尺寸 / 旋转”，拖动彩色手柄。旋转只改变水平 Yaw；需要精确数值时仍可在右侧输入。
4. 需要标记全景中的同一对象时，保持选中该对象，再在全景上点击或绘制多边形。

## 视频流程的轻量版：逐点分类

参考视频：[How to Label 3D Point Cloud for AI Systems: Semi-Automated Workflow](https://www.youtube.com/watch?v=PUens0tKD8M)。视频使用 CloudCompare：先定义类别，以 CSF 分离地面，以 RANSAC 找平面，再用连通组件拆散点群，最后在 Cloud Layers 中用笔刷把点分入类别并导出分类点云。它主要演示语义分割，并非 3D 框调整。

本工具把手工复核步骤缩成：

1. 选类别（右侧按钮或数字键 1–9），切到“点云涂抹”。
2. 在点云中拖动笔刷。笔刷优先涂当前视角下最前面的一层点，减少误选背景。
3. 按 Shift 拖动矩形可一次选取屏幕投影区域内的点；该矩形会选中投影重叠的前后点，复杂场景请检查结果。
4. 按 Alt（macOS 为 Option）涂抹或框选可擦除；点云左下方可撤销最近一次操作。
5. 点击“保存更改”存到本机浏览器，或“导出结果”得到 JSON。`semanticPointLabels` 中每条记录为原始点索引 `pointIndex` 和类别 `classId`。

当前未实现视频中的 CSF、RANSAC、连通组件自动分割，也不会修改原始 PCD/PLY 文件。对于特别密集的点云，浏览器存储空间可能不足；请定期导出 JSON。重新采样或重排点云后，逐点标签索引不再对应原文件。
