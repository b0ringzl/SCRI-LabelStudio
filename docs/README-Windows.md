# Atlas Studio · Windows 版

## 本地打开

1. 安装 Node.js 20 或更新版本。
2. 解压整个 ZIP，双击 `Start-Atlas-Windows.bat`。
3. 脚本会在默认浏览器中打开工作台。保持命令窗口运行；按 Ctrl+C 结束。

此版本已经包含构建好的界面与可共享的合成演示样本，不需要另行安装 npm 依赖，也不会修改其他项目。GitHub 构建不包含本次真实道路设施数据或此前的真实点云与全景样本。服务只监听本机 `127.0.0.1`，默认尝试端口 43127；若被占用会自动尝试后续端口，并在窗口中显示实际地址。关闭窗口后地址失效，重新双击启动即可。

默认首页是“道路设施复核”。点击“选择数据文件夹”并选择整个 `data_for_annotation`（含 `images/`、`labels/`、`class.txt`）；检查 900 张图片的已有 YOLO 框后，导出新的 YOLO ZIP。真实道路设施数据不在安装包中，也不会修改原始文件。操作与七类规则见仓库 `docs/ROAD_FURNITURE_REVIEW.md`。

若要试用辅助模型，在“预标注接口”添加与任务类型匹配的 HTTP 服务，再返回标注页选择并运行。预测先显示为候选，需人工接受。包内 `docs/MODEL_SWITCHING.md` 和 `docs/MODEL_API.md` 说明配置及协议；没有附带真实模型。

也可接入千问或 DeepSeek 视觉模型。先按 `docs/LLM_PROVIDERS.md` 在 PowerShell 设置对应 Key、服务根地址及允许的模型名，再从同一 PowerShell 启动 `.bat`；在配置页选择对应提供方。Key 不写入浏览器或交付包。

人工确认图片后，可在道路设施复核页点击“导出蒸馏清单”，得到仅含已确认样本和教师来源的 JSON。原图需另外提供给训练服务；此包不执行学生模型训练。服务接口、评估隔离和数据格式见 `docs/DISTILLATION_API.md`。

选中 3D 框后可在点云左下角拖动“移动 / 尺寸 / 旋转”手柄；“定位到框”便于精修。视频式逐点分类可用“点云涂抹”：选类别后拖动，Shift 框选，Alt 擦除，支持撤销。导出 JSON 同时包含对象框与逐点类别。

如果浏览器没有自动弹出，复制命令窗口中 `Atlas Studio 已启动：` 后面的完整地址，在浏览器中打开。

## 参与开发

从 GitHub 克隆源码后运行 `npm ci`、`npm run dev`。开发服务器也只监听本机，并在端口占用时换端口。构建和生成两平台交付包分别使用 `npm run build`、`npm run package`（打包需要 Python 3）。
