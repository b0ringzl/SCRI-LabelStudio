# 0.15.0 · 无权重自动精配准

## 移除与替换

按团队要求移除原神经网络配准适配器的前端模块、Python worker、Node 网关、旧 API、模型环境配置、专用测试及部署/权重文档；清理 README、平台说明、配准手册和发行包引用。Git 历史保留，未强制推送或重写提交。

## 新增功能

1. 独立 CPU 球面 NID 六自由度局部优化，无需 checkpoint/CUDA/Docker；保留原始强度/真实 RGB 输入边界。
2. Windows/macOS 独立安装器、依赖就绪探测和对应 ZIP，环境限定本项目。
3. 粗配准主入口、当前帧/批量处理、运行取消、候选预览/原位姿对照、应用/舍弃。更改任务/位姿取消旧请求；应用时检查初值未变。
4. 可见点筛选、训练/留出改善、错误朝向对照、搜索边界与修正幅度检查；失败保留原位姿。应用后使相关旧目标定位失效。
5. registration/2.0 本机接口、严格有限值/数组验证、12 MiB 请求限制、并发忙反馈、断开清理和超时。
6. Windows/macOS 图解 PDF、Markdown、API 与实测说明同步更新。

## 已验证与实际限制

构建及配准、同步、轮廓、模型接口等回归测试；真实优化器已知位姿恢复测试；四组真实场景共 12 帧只读实测，2 帧通过候选筛选、10 帧保留初值。候选没有独立精度真值，不能宣称达到 4° 或已经免去大部分人工操作。详细结果见 [自动配准说明](AUTOMATIC_REGISTRATION.md)。

这不是 Koide 官方 C++ 的封装。尝试官方容器遇到本机 Docker Desktop 服务访问错误后，未重置其他项目环境，改用项目独立 NumPy/SciPy 实现。当前需要粗位姿，尚未实现无初值全局配准、跨帧共享外参联合优化或自动精度认证。
