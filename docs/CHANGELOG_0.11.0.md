# 0.11.0 · 同步配准工作台与高密场景

1. **分屏/叠加切换**：将点云投影叠加作为独立的全宽布局；分屏保留左右独立视图，布局切换保留观测方向。
2. **双向相机同步**：新增 `ViewSync`。默认以当前全景的光心观察点云，共用世界朝向与垂直 FOV；两侧拖动、缩放双向联动。切帧采用新位置并保持世界朝向；观察不修改标定外参。保留自由三维模式。
3. **切帧一致性**：图片载入期间遮住旧画面并阻止画布标注；过期图片回调不应用；纹理提交后两侧一起恢复操作。
4. **精调流程**：三步“粗配准 → 同名点精调 → 投影核验”。同名点使用源点坐标，并在两侧显示相同编号；加入撤销上一对。求解通过后进入投影核验，误差过大时维持原位姿。
5. **点云质量**：空间体素去重避免重复点挤占预算。新私有试用场景扩大到 55m，保留 450 万点（此前 75 万），原始 11 张 8K 全景保持不变。增加高程、亮度与原色显示、固定像素点大小，移除压暗远处点的雾效。
6. **原始颜色隔离**：保存 `sourceColor`，显示增强或语义涂抹不会被彩色 yaw 算法误当成真实颜色。
7. **界面减负**：粗配准页隐藏标注工具和模型栏；相机参数、算法服务、详细点对及诊断折叠到“更多设置”；帧列表改为上一帧/选择/下一帧。标注页模型栏默认折叠，原接口继续保留。
8. **朝向试验**：提取器增加显式 `--panorama-yaw-offset`，默认零；本机高密场景使用待核验的 180° 朝向粗初值并保留 INS-only 备份。没有应用待确认 CSV，没有宣称达到 4° 精度。
9. **双平台与协作**：同一代码生成 Windows/macOS 平台及本机私有场景包。新增同步、颜色来源和空间采样测试并加入 CI，新增完整使用与开发说明。

验收范围、源码映射、启动和复现见 [同步观察与精细配准](SYNCHRONIZED_REGISTRATION.md)。真实数据不进入 Git；实体 Mac 上的图形性能仍待验收。
