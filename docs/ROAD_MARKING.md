# 路面标识旋转框

在「标注 → 点云 + 全景 → 路面标识」打开俯视点云。左侧用 LiDAR 强度显示路面，右侧保留全景供辨认。有位姿时，俯视图从当前相机前方开始，准星可以定位到切换后的帧。没有位姿时可从点云中心开始标注。使用 +Y 向上的场景坐标。

1. 左上角选择标识类型，在空白处按住左键拖出初始框。
2. 拖动圆形手柄旋转，按住 Shift 可按 15° 对齐。拖框内移动，拖四角调整宽长。滚轮缩放，右键或 Shift 加左键平移。
3. 点「新建框」可取消当前选择，选择下一实例的类型。撤销、重做支持界面按钮及 Ctrl／Cmd+Z。Delete 删除当前对象。
4. 用「保存更改」保存到当前浏览器，用「导出结果」保存 JSON。普通三维点云也会显示已保存的框线。

| 类型 | 框的范围 |
| --- | --- |
| 菱形、箭头、文字或独立符号 | 每个标识一个框，转到与标识主轴平行 |
| 斑马线 | 一组条纹一个框，按该组整体范围标注 |
| 停止线、车道虚线段、实线段 | 框住可辨认的直线段。虚线每段一个框。长曲线可分段记录 |

设计参考 [WHU-Road3D 官方标注说明](https://github.com/WHU-USI3DV/WHU-Road3D#annotations)。该数据集还提供车道折线、条纹和轮廓等精细表示。本工具输出路面对象的范围和朝向。对于空心菱形和条纹间隙，框内部仍可看到原始点，不会写入逐点类别。

## 导出字段

`annotations[].roadMarking` 是联合标注 JSON 中的可选字段。`kind` 为 `road-marking-box`，`type` 为标识子类，`center` 和 `corners` 使用点云场景坐标，`size` 为平面宽和长，`yaw` 表示长轴从 −Z 顺时针转过的角度，以俯视图为准。四个角的 Y 从附近低层点估计，缺点时沿用框中心高程。俯视使用局部低层点以减少车辆、建筑等立体物体干扰，遇到高差或遮挡应参考全景核对。旧的 3D 框、全景标注和逐点标签沿用原有字段。

## 本机 WHU-STree 测试场景

试用包从本机已有的 [WHU-STree 南京数据](https://github.com/WHU-USI3DV/WHU-STree) 提取三个 55 m 局部场景，分别包含菱形与车道虚线、导向箭头与车道线、斑马线与停止线。各含五张原始全景和官方修正后的逐帧位姿。WHU-Road3D 作为标注设计参考，原始数据需从官方申请。

完整解压后，Windows 双击 `Start-Tests-Windows.bat`。macOS 在解压目录执行 `sh ./Start-Tests-macOS.command`。启动需要 Node.js 20+，绘制和编辑框无需另外安装模型。采集数据的试用包保留在本机。
