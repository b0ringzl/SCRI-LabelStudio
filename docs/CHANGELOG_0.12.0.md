# 0.12.0 · 点云覆盖修复与跨场景导入验证

用户反馈点云缺少大片数据，且要求换几组真实数据验证自动化。本轮将“只展示尖沙咀的局部样本”扩展为完整地图概览和可复用的位姿导入链路。

| 改动 | 结果与代码入口 |
| --- | --- |
| 追溯缺块 | 发现旧流程只读第 5 块并裁到 55 m；审计显示源抽样约 44.8% 在半径外。高度筛选不是此次近区缺块主因。 |
| 补全覆盖 | `complete_scene_coverage.py` 合并全部 12 个 DS 分块的全局概览和 450 万局部 RGB 细节，共 6,215,955 点。概览无地理裁剪，保留降采样和来源说明。 |
| 通用自动导入 | `pointcloud_io.py`、`import_scene_dataset.py` 按每组自己的 CameraPoseInSlam 位姿转换坐标，默认全图采样、全部影像；显式坐标配置，无场景固定 yaw。 |
| 独立导入入口 | Windows/macOS 各有 Import-Scene 启动器；依赖装在本目录虚拟环境。校验矩阵、帧 ID、全景比例、PCD 完整性，拒绝覆盖输出目录。 |
| 多场景切换 | `sceneCatalogGateway.mjs` + `sceneImport.ts`，只读清单和 key 路由，按内容派生独立任务 ID；切换场景前保存当前记录，避免逐点索引串用。 |
| 缺位姿门控 | 当前帧没有源/保存位姿时关闭同步，避免默认原点被误当作正确配准。 |
| 改善稀疏显示 | 强度数据使用鲁棒范围而非虚构 RGB；点径随间距/距离/FOV 调整，错误显示提示回退固定点径。 |
| 四场景验证 | campus、floor6、library 加尖沙咀，32 帧切换及各组双向拖动/缩放通过；三个新数据源共 552 张全景与位姿匹配并验证格式，试用复制其中 21 张。 |
| 可复现与交付 | 新增 Node/Python 回归、真实目录集成验证脚本、完整导入/UI 文档；常规及含数据试用包均输出 Windows/macOS。 |

验证：TypeScript/Vite 构建、既有模型/蒸馏/配准/本机场景/视角同步回归，以及新目录路由、坐标转换、文件损坏和缺位姿回归。CI 在 Windows/macOS 跑 Python 场景回归，Linux 跑 Node 回归和双平台打包。真实数据与完整报告、截图留在忽略目录，未上传仓库。

提交按三部分组织：`4cf9e2d` 为通用导入、坐标配置、双平台启动器与 Python 回归；`6ddf11c` 为地图覆盖补全、多场景 UI/文件服务、显示与同步门控、Node 回归；最后一项提交更新版本、文档、双平台打包及解压后服务冒烟测试。PR 集中说明全部功能和能力边界，便于逐提交阅读。

边界：源 SLAM 位姿的自动使用不等于无位姿数据的自动标定；同步相机的数值一致不等于点云与影像真实误差达标。尖沙咀的 INS + 180° 仍是待核验初值，三组新场景未使用该修正。本次没有独立 4° 真值验收，也没有室内数据的额外验证。实体 Mac 图形性能待验收。详细复现和测试矩阵见 [跨场景导入与验证](SCENE_IMPORT_VALIDATION.md)。
