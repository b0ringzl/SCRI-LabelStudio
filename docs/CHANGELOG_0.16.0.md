# 0.16.0 — 接入 DA² 单全景深度辅助配准

## 新增功能

- 配准页增加 DA² / NID 方法选择，沿用同一个候选预览与应用流程，未增加左侧导航项。
- 官方 DA² 权重可在本机对单张全景推理，支持查看相对深度图、真实运行设备和纯前向耗时。
- 新增基于径向深度的局部六自由度与尺度联合求解。点云只需 XYZ，不要求强度或 RGB。
- 使用完整角度小块留出检查、鲁棒多起点、边界和修正范围筛选。拒绝的位姿仍可查看深度，原位姿保留。
- 接入后可切换原位姿/候选、逐帧或批量计算、取消、应用/舍弃；应用后记录 `auto-depth` 来源并使关联多帧定位待复核。
- 新增独立 DA² 安装器、固定源码/模型版本、SHA-256 校验与内容缓存。Windows 与 Apple Silicon macOS 使用同一接口。

## 实际部署

- Windows 项目独立 `.venv-da2` 已部署 CUDA 推理，无改动 TREE 环境。
- 源码固定为 `d659838585f2bc9967c7e9367af573795271dbbb`；权重固定为 `0d55ccb5e46b8ed4715fae3a4c04fc897f1689f3`。
- 完整权重 1,378,513,064 字节，SHA-256 `d8ea568fc3dfb7d7432e5b763de499dd03fb6dc1c2020d84639f35e2dfa4f78e` 校验通过。
- 本机模型前向约 0.88–0.95 秒/张，峰值显存约 2.82 GiB。图像预处理、启动、读权重与几何求解不在该前向时间内。
- Mac 包提供安装与启动脚本；MPS 尚未进行真实 Mac 设备验证，不能将 Windows 测试写成 Mac 性能结果。

## 真实数据验证

五张图像来自四组现有真实场景，没有使用生成的全景替代，也没有修改源位姿或标注。5/5 输出了真实模型深度，2/5 通过内部候选筛选；这是候选数量，不是配准精度成功率。

| 场景/图像 | 留出区域对数深度残差中位数 | 结果 |
| --- | --- | --- |
| 六层 / 76.jpg | 0.200 → 0.175 | 位姿候选，仍需独立核验 |
| 六层 / 72.jpg | 0.175 → 0.161 | 位姿候选，仍需独立核验 |
| 图书馆 / 4324.jpg | 0.512 → 0.392 | 拒绝：残差仍高且 P75 恶化 |
| 校园 / 100.jpg | 0.220 → 0.171 | 拒绝：留出 P75 恶化 |
| 尖沙咀 / frame_001298.jpg | 0.349 → 0.315 | 拒绝：残差仍高 |

浏览器完整走通“真实全景/点云 → DA² 推理 → 深度图 → 位姿候选 → 原位姿/候选切换”，六层 76 帧显示留出残差约 0.197 → 0.175。浏览器和命令行的 JPEG 编码、采样稍有不同，因此数值不完全相同。建筑投影仍有可见错位，本次没有点击应用或写入源位姿；不能据内部指标宣称配准已验收。

所有真实图像、深度和截图仅保存在本地忽略目录，不进入公开 Git 或发行包。Windows/macOS 发布包通过解压启动检查；Mac 上的真实模型与图形性能仍待实机验证。

## 验证范围

新增坐标/像素中心、尺度与已知位姿恢复、无结构/无效输入拒绝测试；新增前端 XYZ-only 采样、API 同源、候选门槛和可选真实 DA² 端到端测试。CI 加入几何检查和接口检查，发布检查验证两平台 ZIP 包含模型接口和安装器且不带模型或调查数据。

首次线上 Windows 检查发现英文系统 CP1252 控制台无法打印中文测试诊断；已将测试日志改为 ASCII 状态和数值，并以 CP1252 编码复测。此修复不更改模型、求解或候选门槛。

本版仍为实验性局部精配准，不能宣称无初值全局配准、普遍改善或实际角度误差小于 4°。
